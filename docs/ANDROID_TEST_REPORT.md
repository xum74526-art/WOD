## 本轮发现并修复

- Android JavaScript 运行时缺少 `Intl` 和部分 `Array.prototype.at`，导致首页行情空白或日期显示异常；已换成确定性格式化和兼容写法。
- 市场快速输入搜索会使用上一个字符；已从确认事件获取最终值。
- 通知列表和钱包流水在 Android 上会把 `undefined` 序列化为无效 GET 参数，造成 422；已改为仅发送实际存在的筛选参数。
- 钱包流水直接显示内部事件名且伪造“交易后余额 0”；已改为友好名称，接口未返回余额时不再虚假展示。
- 可提现余额误用可消费钱包余额；在真实收益结算未接入时改为 0 并禁用提现。
- 个人资料把未短信验证的登录手机号误显示为“未绑定”；现在展示号码并明确标注“仅作为测试登录标识”。
- 登录、设置、实名认证和协议中的旧 WOD 品牌文案已统一为 KAI（保留历史优惠码和内部兼容键）。
