# 重构实施状态

更新日期：2026-08-21

## 已完成

- 新建独立 `KAI-Unified` 仓库，旧项目不参与编译。
- Web、iOS、Android、Agent 统一连接 FastAPI `/api/v1`，没有 `/api/mobile/v1` 迁移层。
- Mobile 118 个可执行网络请求通过静态 AST 契约审计，旧路径、未知路径和绕过统一请求层的访问均为 0。
- App 已迁移身份、资料、通知、商品、行情、订单、租约、求购报价、供应商、钱包账本、提现、KYC、资讯评论等 ViewModel。
- 后端补齐原生 Token 资料修改、密码修改、通知偏好、钱包账本，以及文章/视频统一关注能力；商品图片和统一外部身份已纳入数据模型，数据库迁移到 `0029_unified_auth`。
- Web 与 Mobile 均支持“邮箱或手机号 + 密码”和 Kai 统一认证；密码账号跨端共用，Kai 使用授权码 + PKCE、状态防重放、已验证联系方式绑定和一次性 App 票据。当前本机未提供 Kai 客户端凭据，因此入口明确显示未配置。
- 社区保留“推荐 / 关注 / 最新 / 视频”四标签；推荐采用偏好、时效、热度及内容多样性规则，关注内容跨设备存入统一数据库。
- Mobile 与 Web 的“算力市场”共用 `/api/v1/public/products`；Mobile“行情曲线”与 Web“算力行情”共用 `/api/v1/public/market/summary` 及同一套 4/8/14 周历史数据。
- 本地开发库已由可重复脚本生成 120 台演示服务器，覆盖 27 个 GPU 型号、8 个演示商家和 10 个地区；120 条商品均带有型号图片，所有演示资源均显式标记，不冒充真实库存。
- Mobile 算力市场采用双列商品卡片，展示型号图、在线状态、显存、地区、CPU/内存、带宽、价格和商家。
- Web 使用 Cookie + CSRF，App 使用不透明 Bearer Token；两个通道不能互相重放。
- 无真实实现的旧功能不再请求假接口：未配置时明确禁用或返回不可用。
- iOS 26.5 模拟器已用测试账号真实登录统一后端，网络异常问题已经修复。
- H5 与 App 双平台业务资源已经编译；Android 16 模拟器已完成登录、五个主标签及钱包、订单、通知、设置的完整回归。

## 尚未等于“生产上线”的部分

- DCloud AppID、正式 iOS Bundle ID、Apple 签名、Android 包名和 keystore 尚未由项目所有者提供，因此没有正式 IPA/APK/AAB。
- Kai、支付、短信、邮件、对象存储、推送等第三方服务仍需生产账号与密钥。
- PostgreSQL 并发、支付对账、库存竞争、真机兼容和商店审核仍属于发布门槛。
- 当前 UI 保留移动端“卡时”等旧产品表达；后端金额以明确币种为事实来源，正式运营前需最终确认换算和文案规则。

此文档不把“接口统一并能编译”误写成“全部外部服务已上线”。
